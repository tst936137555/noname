# 工程修复说明

本轮保留玩法、模式规则和武将强度设定，落实工程审计中已确认的故障与安全边界修复。

## 已落实

- 文件服务只读，移除 HTTP 写入与删除路由；检查请求来源、Host、真实路径、目录联接和私有目录。静态文件也经过路径检查。
- 联机命令仅允许自有处理函数，握手前不处理业务命令；消息异常不会终止进程，限制载荷、频率、连接数量与发送缓冲。
- 私有会话凭据与公开标识分离，服务端仅保留凭据摘要，不再在玩家列表广播登录标识；拒绝重复身份、房间覆盖与错误凭据。
- 入房校验成功后才提交状态，房主离开后清理客机归属。
- Electron 使用隔离、沙盒及 CJS preload，仅暴露退出操作、旧配置目录标识及有限的局域网房主消息桥；限制外部导航，固定 localhost 来源维持存档兼容，端口冲突直接报错。
- 桌面缓存、日志与存档移至用户数据目录，首次使用时复制旧 UserData，旧文件保留。
- 存档导入有结构、配置类型、深度与大小校验；配置和数据在同一事务写入，同时保留上一份恢复快照。事务中断时原数据不变。
- 普通数据库写入等待事务提交；数据库升级阻塞有明确错误提示，多窗口版本变更主动关闭连接。
- 事件执行使用 finally 恢复事件栈。
- 模式选择前不加载大型内容包，选择后再加载并顺序注册，保留全部包之间的依赖。启动任务有超时、进度与阶段计时。
- 发行构建移除 JIT 注入、编译器 Service Worker 和自动刷新代码；不再自动执行首次触屏切换重载，所选模式加载使用同一超时计时器。
- 浏览器静态托管可以在无文件接口时使用 IndexedDB 和下载；导出 Blob URL 延迟释放。
- 卡牌布局预先计算数量与分组，减少循环过滤。
- 关于页增加诊断导出，记录有限数量且去重的异常及启动计时，诊断不包含配置、存档或会话凭据。
- 模式选择可聚焦并具备键盘入口，固定主题添加焦点提示、减少动态效果和安全区域样式；iOS 明确拒绝路径回退片段。
- 发布与打包先准备完整临时目录，再替换旧目录；复制失败保留旧产物。
- PR、Nightly 与 Release 增加回归测试及类型基线检查；测试自动发现，避免漏掉新增文件。

## 使用与兼容

`pnpm test` 运行回归；`pnpm lint` 检查代码；`pnpm check:types` 阻止历史基线之外新增的类型诊断；`pnpm test:browser` 在 Electron 隐藏隔离窗口中验证发行包，需要先构建核心及 Electron preload，且安装 Electron 二进制。测试使用独立临时配置，不接触用户存档。`pnpm audit:assets` 生成 `output/resource-audit.json`，不删除资源。

自己的联机大厅需要和本轮客户端一起部署，旧客户端缺少私有握手凭据，会被拒绝。服务器重启会清空本次进程的房间与会话记录。会话凭据只留在客户端 localStorage，切勿在大厅明文日志中记录。

存档导入恢复快照保存于 data store 的 `__noname_import_backup__`，可以在存档管理中恢复。发生导入事务错误会自动回滚，无需手工恢复。

## 尚未完成的长期事项

历史类型错误仍大量存在。类型基线取自修改前的审计日志，检查通过表示未增加错误，不能表示全量类型检查零错误。需要逐模块修复，并同步降低基线，不能扩大基线掩盖新增错误。

资源审计发现 13,841 个图片、音频和字体文件，约 1.15 GiB，完全重复内容约 3.46 MiB。动态路径、共享音效与立绘仍需引用关系审计；本轮未重编码或批量删除资源，也未声称获得显著安装包缩减。

大型引擎文件尚未全面拆分。独立了存档仓库、诊断模块及发布目录操作；后续还需在行为回归保护下逐步拆分网络和 DOM 职责。

Android、iOS 的签名安装、真机长局、断网恢复、高 DPI 与触屏可读性仍需要对应平台验收。桌面隔离后经浏览器路径运行，不再向页面暴露 Node.js；桌面局域网房主使用主进程固定端口消息桥，页面无法任意监听端口或访问原生对象。
