# 精简版

游戏统一使用固定十周年风格，沿用现有长布局、流沙牌背、玻璃体力条和武将图片，新增墨色铜金主题。此主题基于本仓库实现，不包含第三方“十周年 UI”扩展。外观设置和扩展入口已移除。

卡牌名称使用随包新魏字体，装备栏、花色和点数分别采用固定排版；普通装备和视为装备共用文字格式。字体不再优先使用设备上同名的本地字体，避免不同设备字形不一致。界面、卡牌、字体、按钮与记录栏等显示选项统一锁定，读取旧存档和保存配置时同样生效。

选项菜单分为对局设置、操作设置、声音设置和存档管理，保留对局速度、自动响应、鼠标／触屏输入、音乐音量和存档导入导出等必要内容。移除显示开关、字体样式、开发调试、作弊、技能禁配和自定义音乐管理入口。输入相关选项按设备和开关状态显示；菜单选中标记随标签布局，下拉菜单按实际缩放定位并限制在窗口内。

移除首次新手向导及其重置入口。普通启动先显示进度条，准备模式封面和固定界面图片、字体后进入模式选择，选择后才加载模式代码、包体及资料；重开对局和录像播放保持直达。预加载最多并发 4 个任务，包体注册按顺序分批完成，首次进入也按需创建菜单，避免一次生成全部武将和卡牌按钮。立绘和语音继续按需加载，避免过度占用内存。必要内容加载失败时显示重试入口，装饰图片或字体失败、超时则交由浏览器按需加载。

保留身份（默认八人）、国战、斗地主、单挑、对决（2v2、3v3、4v4）和联网。移除挑战、乱斗、战棋、炉石、塔防及实时模式的注册、导入和构建入口。

保留标准、神话再临、经典神将、一将成名、界限突破、璀璨星河、系列专属、新一将成名、OL 专属、文德武备、门阀士族、群英荟萃、限定专属、移动版、始计篇、谋攻篇、兵势篇、联动卡和怀旧。海外、线下、江山如故、蚀心入魔、四象封印、DIY、Key 包不再加载或构建。混合命名的 `ol_tw_zhangji`、`mb_tw_zhangji` 和移动版限时地主等按所属三端包保留，不按名字中的 `tw` 误删。

唯一清单在 `apps/core/noname/util/product.js`。启动时清理旧存档中的不支持内容，失效模式回退到身份，外观恢复固定搭配；联网地址、昵称及保留模式的游戏设置继续保留。

被排除的模式、武将包和修仙牌包源码，以及扩展菜单、扩展模板与废弃 PhantomJS 脚本已从仓库移除。共用图片、音效及技能依赖资源暂时保留，以免影响三端武将技能。

构建时本体先完成，武将、模式和卡牌包通过最多三个独立工作线程并行构建。使用 `NONAME_BUILD_WORKERS=1` 可限制为单线程；详见根目录 README。

发布统一为全量版，包含游戏代码、图片、字体、音频及当前保留内容。移除在线升级、更新源、素材包导入、游戏文件管理和旧资源版本配置；武将包、卡牌包管理及存档导入／导出保留。`pnpm package` 生成可独立运行的 `output/noname/`，不再生成增量测试包，iOS 不再裁剪立绘和语音。

唯一维护的游戏版本号在 `apps/core/package.json`；桌面和移动安装包使用相同版本号，平台要求的构建编号从该版本计算。发布标签需与游戏版本一致。

验证：`pnpm test`；核心构建：`pnpm -F noname... build`。

浏览器首次启动会显示仓库原有的 GPL 协议确认，需由使用者自行确认。构建和配置迁移检查不能替代实际联网对局回归。
